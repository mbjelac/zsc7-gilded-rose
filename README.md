# Zagreb Software Crafters #7 - Mob programming workshop

The purpose of this repository is to record the development flow during the [mob programming workshop](https://www.meetup.com/zagreb-software-crafters/events/313498126) on Zagreb Software Cratfers meetup #7 which took place on 2026-04-27 in Zagreb.

The original repository is [here](https://github.com/emilybache/GildedRose-Refactoring-Kata). We forked it and I removed all stuff we didn't use.

I advise you look through commits from `ba505f23e45afe330326c8f82d591811841289fb` onward.

This was mob programming, so changes were made by various persons, which is visible if you study the diffs.
